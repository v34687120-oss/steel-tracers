STEEL TRACERS — ЗАПУСК НА MAC
Версия архива: 1.2.7 (30.10.2026)

ЧТО ЛЕЖИТ В АРХИВЕ
------------------
SteelTracers/             — игра (Windows-сборка Unity). Именно её запускает PlayOnMac.
SteelTracers-Windows.zip  — та же сборка одним архивом для Windows-ПК.
PlayOnMac_4.4.4.dmg       — официальный установщик PlayOnMac (Wine-обёртка).
README-MAC.txt            — эта инструкция.
SHA256SUMS.txt            — контрольные суммы файлов.

ВАЖНО ПРО MAC
-------------
Нативной macOS-версии (.app) пока нет: Unity собирает macOS-билд только на Mac,
а эта сборка сделана на Windows. Поэтому на Mac игра запускается через
PlayOnMac — бесплатную обёртку Wine. Это не «эмулятор Windows целиком»:
игра открывается в обычном окне macOS, а PlayOnMac переводит вызовы Windows
в понятные macOS команды.

На Apple Silicon (M1/M2/M3/M4) PlayOnMac работает через Rosetta 2.
Если не хочется ставить Rosetta и PlayOnMac, есть альтернатива Whisky —
см. раздел «Если PlayOnMac не подходит».

ЧТО НУЖНО
---------
- macOS 10.15 Catalina или новее (официальное требование PlayOnMac 4.4.4).
- 8 ГБ оперативной памяти (минимум 4 ГБ, но будет тяжело).
- Около 2 ГБ свободного места: установщик 574 МБ + распакованная игра + Wine-префикс.
- Интернет при первом запуске PlayOnMac: он скачивает компоненты Wine.
- Intel Mac или Apple Silicon с установленной Rosetta 2.

ШАГ 1. ПРОВЕРЬ ВЕРСИЮ MACOS
---------------------------
Меню Apple → «Об этом Mac». Нужна macOS 10.15 или новее.
Если у тебя macOS 10.13/10.14 — PlayOnMac 4.4.4 не подойдёт, нужна
старая версия 4.3.3 (228 МБ) с сайта playonmac.com.

ШАГ 2. APPLE SILICON: ПОСТАВЬ ROSETTA 2
---------------------------------------
PlayOnMac 4.4.4 — Intel-приложение. На M1/M2/M3/M4 без Rosetta 2 оно
не запустится.

1. Открой «Терминал» (Программы → Утилиты → Терминал).
2. Вставь команду и нажми Enter:

   softwareupdate --install-rosetta --agree-to-license

3. Дождись окончания. Если Rosetta уже стоит, команда просто это скажет.

ШАГ 3. УСТАНОВИ PLAYONMAC
-------------------------
1. Дважды кликни PlayOnMac_4.4.4.dmg.
2. В открывшемся окне перетащи PlayOnMac в папку «Программы» (Applications).
3. Открой «Программы» и найди PlayOnMac.
4. Первый запуск: не двойной клик, а правый клик по PlayOnMac → «Открыть» →
   в диалоге ещё раз «Открыть». Так macOS разрешит неподписанное приложение.
   Если такого пункта нет: «Системные настройки» → «Конфиденциальность и
   безопасность» → внизу «Всё равно открыть».
5. Если macOS пишет «PlayOnMac повреждён и не может быть открыт» (частая
   реакция Gatekeeper на скачанные из интернета неподписанные программы),
   выполни в Терминале:

   sudo xattr -rd com.apple.quarantine /Applications/PlayOnMac.app

   Введи пароль Mac (символы не отображаются — это нормально), затем снова
   открой PlayOnMac.
6. При первом запуске PlayOnMac может предложить скачать компоненты Wine
   (wine-mono, wine-gecko, XQuartz). Разреши установку и подожди.
   Если предложит выбрать версию Wine — оставь версию по умолчанию.

ШАГ 4. СОЗДАЙ ВИРТУАЛЬНЫЙ ДИСК ДЛЯ ИГРЫ
---------------------------------------
Это «папка Windows» внутри Mac, где будет жить игра.

Способ А — через мастер установки (рекомендуется):
1. В PlayOnMac нажми «Install a program» (Установить программу).
2. Выбери «Install a non-listed program» (Установить программу, которой нет
   в списке) → Next.
3. Выбери «Install a program in a new virtual drive» → Next.
4. Назови диск: SteelTracers → Next.
5. Если появится выбор разрядности — выбери 64-bit (игра 64-битная).
6. Когда мастер попросит установщик, выбери «Use a file on my computer»
   (Использовать файл на компьютере) и укажи:

   .../SteelTracers/SteelTracers.exe

   (папка SteelTracers из этого архива).
7. Игра запустится. Дойди до главного меню и закрой игру (Cmd+Q или Esc).
8. Мастер предложит создать ярлык. Назови его SteelTracers и выбери
   SteelTracers.exe. Готово.

Способ Б — если мастер не сработал:
1. PlayOnMac → «Configure» (Настроить).
2. Нажми «New» (Создать), назови диск SteelTracers, выбери 64-bit.
3. Выдели диск в списке слева → «Configure Wine».
4. На вкладке «Applications»/«Приложения» поставь Windows 10 → Apply → OK.
5. Вернись в окно Configure → вкладка «Miscellaneous» (Разное) →
   «Run an .exe file in this virtual drive» → выбери SteelTracers.exe.
6. Чтобы сделать ярлык: Configure → выдели диск → «Make a new shortcut from
   this virtual drive» → выбери SteelTracers.exe → назови SteelTracers.

ШАГ 5. НАСТРОЙ WINE ПЕРЕД ПЕРВЫМ БОЕМ
-------------------------------------
Выдели диск SteelTracers в PlayOnMac → «Configure Wine»:

- Вкладка «Applications»: Windows version = Windows 10. Apply.
- Вкладка «Graphics»: включи «Automatically capture the mouse in full-screen
  windows» (автозахват мыши в полноэкранном режиме).
- Если игра открывается в странном маленьком окне или чёрном экране:
  включи «Emulate a virtual desktop» и задай 1280x720.
- Вкладка «Audio»: оставь CoreAudio. Если звука нет — попробуй другой
  аудиовыход и перезапусти игру.
- Не включай Retina/HiDPI, если картинка мыльная или тормозит.

ШАГ 6. ЗАПУСК И НАСТРОЙКИ ГРАФИКИ
---------------------------------
1. В PlayOnMac выбери ярлык SteelTracers → «Run» (Запустить).
2. Первый запуск может занять 1–3 минуты: Wine создаёт окружение.
3. В игре сразу открой настройки графики:
   - качество — Low/Низкое;
   - тени — выключить;
   - разрешение — 1280x720 или 1440x900;
   - V-Sync — выключить, если FPS низкий;
   - полноэкранный режим — попробуй и так, и так.
4. На MacBook Air M1 при низких настройках ориентируйся на 30–50 FPS.
   На Intel-графике и старых Mac будет ниже. Это нормально для Wine:
   игра не нативная, часть производительности теряется.

СЕТЕВАЯ ИГРА 1×1
----------------
- Оба игрока должны запустить одну и ту же версию игры (1.2.7).
- Хост в игре создаёт комнату. Второй игрок подключается по IP хоста.
- Игра использует TCP 47778 и UDP 47777.
- Если роутер поддерживает UPnP, игра сама откроет порты. Если нет —
  пробрось на роутере TCP 47778 и UDP 47777 на Mac хоста.
- В macOS при первом запуске разреши входящие соединения для PlayOnMac
  (Системные настройки → Сеть → Брандмауэр → Параметры → разрешить).
- IP хоста в локальной сети: Терминал → ipconfig getifaddr en0
  (для Wi-Fi; если пусто — en1).
- Для игры через интернет может понадобиться проброс портов на роутере
  и внешний IP. Проще всего играть в одной локальной сети.

ЕСЛИ ИГРА НЕ ЗАПУСКАЕТСЯ
------------------------
1. Чёрный экран / вылет после логотипа Unity:
   В свойствах ярлыка в PlayOnMac добавь аргументы запуска:

   -screen-width 1280 -screen-height 720 -screen-fullscreen 0 -force-d3d11

   (правый клик по ярлыку → Properties/Свойства → Arguments/Аргументы).
2. «Failed to initialize graphics»:
   - включи виртуальный рабочий стол 1280x720;
   - попробуй другой движок Wine в PlayOnMac (Tools → Manage Wine versions);
   - на Apple Silicon проверь, что Rosetta 2 установлена.
3. Игра запускается, но очень тормозит:
   - выключи тени, поставь Low, 1280x720;
   - закрой браузер и другие тяжёлые приложения;
   - на M1/M2/M3 попробуй Whisky — он часто быстрее PlayOnMac.
4. Нет звука:
   Configure Wine → Audio → CoreAudio; перезапусти игру. Проверь, что
   в macOS выбран правильный выходной девайс.
5. Ошибка «Wine is not installed»:
   PlayOnMac → Tools → Manage Wine versions → установи 64-bit Wine,
   затем повтори создание диска.
6. Не создаётся ярлык:
   Configure → выдели диск → «Make a new shortcut from this virtual drive».
7. Где лог игры:
   ~/Library/PlayOnMac/wineprefix/SteelTracers/drive_c/users/<твой_пользователь>/
   AppData/LocalLow/DefaultCompany/SteelTracers/Player.log
   Открой его текстовым редактором — там причина вылета.

ЕСЛИ PLAYONMAC НЕ ПОДХОДИТ (APPLE SILICON)
------------------------------------------
Whisky — бесплатная альтернатива для M1/M2/M3, работает нативно и часто
быстрее PlayOnMac: https://getwhisky.app/

Кратко:
1. Скачай Whisky, перетащи в «Программы», открой.
2. Создай бутылку (Bottle): Windows 10, 64-bit.
3. В настройках бутылки включи DXVK (для DirectX 11).
4. Нажми «Install» / «Run» и выбери SteelTracers/SteelTracers.exe.
5. Те же настройки графики: Low, без теней, 1280x720.

Whisky не входит в архив — это отдельная программа.

УДАЛЕНИЕ
--------
1. PlayOnMac → Configure → выдели диск SteelTracers → «Uninstall»/удали.
2. Или удали папку ~/Library/PlayOnMac/wineprefix/SteelTracers.
3. PlayOnMac удаляется как обычное приложение: перетащи в Корзину.
