============================================================
STEEL TRACERS — Windows x64
Версия: 1.3.0 (01.11.2026)
============================================================

1. Распакуй SteelTracers-Windows.zip.
2. Запусти SteelTracers.exe.
3. Установка не нужна.

Если Windows SmartScreen предупреждает о неизвестном издателе:
«Подробнее» → «Выполнить всё равно».

В настройках теперь можно выбрать разрешение 720p, Full HD или 2K.
Интерфейс автоматически масштабируется под выбранное разрешение.
В карточке танка показаны исторические углы наклона лба, борта и башни.

Управление:
W/S — ход, A/D — поворот корпуса, мышь — башня и орудие,
ЛКМ — выстрел, ПКМ — приближение, Space — пулемёт,
1/2/3 — тип снаряда, F — ремонт, G — пересадка экипажа,
6 — огнетушитель, V — вид, Esc — пауза.

Сетевая игра 1×1:
хост создаёт комнату, второй игрок подключается по IP.
Порты: TCP 47778, UDP 47777.

Локальный сервер профилей (облачное сохранение):
рядом с игрой лежит папка «SteelTracers Server». Запустите
«Start Server and Play.bat» — сервер и игра стартуют вместе.
Профили хранятся в папке profiles, админка: http://127.0.0.1:47779/admin
Без сервера игра работает офлайн, прогресс сохраняется локально.
